# Danvers Falcons Cross Country

Website for the Danvers High School boys and girls cross country teams.

## Pages
- `index.html` – Home
- `runners.html` – Roster and meet-by-meet results
- `schedule.html` – Schedule and results
- `history.html` – Titles, all-time 5K list, standouts
- `media.html` – News and photos

## Updating results
All results, runners and meets live in **`js/data.js`**. After each meet, edit that one file
(times, places, scores) and commit — the pages update automatically.

## Going live (GitHub Pages)
Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
